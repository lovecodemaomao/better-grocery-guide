# 如何阅读这份指南

这是一份中国大陆普通消费者的采购参考，不提供实时价格，也不把全国市场观察当成某个城市的结论。

## 三种不同的“季节”

- **产地采收**：某品种在所述产区的采摘或成熟时段。
- **集中上市**：资料显示市场到货较集中的时段。
- **市场供应**：能够买到，可能来自冷库、设施栽培、外地或进口；不等于当季采摘。

同一商品可以全年供应，但不同月份的来源和品质并不一样。自然成熟、集中上市与价格低点也不会自动重合。[农业农村部月度分析](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202312/P020231225337393884299.pdf)会明确区分应季柑橘和库存苹果、梨。

## 内容标注

- **可靠资料**：官方资料、农业技术推广、食品安全机构资料等；引用时仍需写清适用范围。
- **可重复经验**：多个独立购物经历方向一致，但没有足够资料证明普遍适用。
- **待核实**：资料不足或结论冲突；不应据此作强推荐。

专业冷库参数只解释商品特性，不直接换算成家用冰箱保存天数。储存建议着重减少损耗；外观正常也不能保证食品安全。发现霉变、异味、腐烂或包装破损时，应停止按原囤货计划使用并检查同批商品。
