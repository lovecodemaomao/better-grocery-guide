# 怎样选购买渠道

先确定商品特点，再比较渠道。平台名称不能替代商品状态、配送条件和售后条款；同一平台不同城市、商家和时段也可能不同。

| 需要核对的事 | 对采购决定的影响 |
| --- | --- |
| 能否现场逐个检查 | 草莓、叶菜、熟番茄等易压伤商品更需要看实物。 |
| 运输与温控 | 运输距离、时长、缓冲包装和需要的冷链会影响到货品质。 |
| 规格是否清楚 | 净重、果径、等级、品种不明时，标价难以直接比较。 |
| 付款与售后 | 运费、起送门槛、优惠条件和破损退赔都计入到手成本。 |
| 家庭食用速度 | 大包装若吃不完，损耗可抵消折扣。 |

## 常见渠道怎样使用

- **菜市场、农贸市场**：适合现场检查成熟度、碰伤和实际规格；比较时记下净重与价格。
- **超市、社区生鲜店**：适合对照标签、包装日期与规格；也要检查底层商品。
- **即时零售**：适合时间成本高、急需补货时比较配送时效、起送门槛和售后。
- **传统电商**：更适合规格清楚、能承受运输、包装与售后明确的商品；鲜果仍应核对产地、品种和到货风险。
