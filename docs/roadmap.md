# 阶段计划与进度

优先完成每月水果、蔬菜清单和可用的零售比价。每条季节线索都要保留品种、产地、观察年份与直接来源；历史市场供应不能写成今年实时行情。

| 阶段 | 工作 | 完成条件 | 状态 |
| --- | --- | --- | --- |
| 1. 月历可用 | 十二个月分列水果、蔬菜；每条注明采收、集中上市或市场供应 | 每月两类都有记录，生成与来源检查通过 | 已完成首版 |
| 2. 零售比价可用 | 同城同商品按净重、优惠、运费换算元/公斤，记录价格口径与日期 | 可录入京东、盒马等平台价格并筛选比较；过期提醒可见 | 已完成本地记录版；青浦 12 种绿叶菜连续三期监测范围与过期提醒已上线 |
| 3. 公开价格样本 | 先查上海青浦区，再扩展上海其他区、北京、广州、深圳；核实各平台高销量或高热度商品 | 至少两个平台有同区同日、相近规格且可复查的零售样本，才发布公开比较 | 青浦区参考监测已整理；平台价待采集 |
| 4. 月历补全 | 增加更多常见蔬菜、约三十种水果，复核区域和品种差异 | 新条目有直接来源；没有证据的月份标待核实 | 已加入全年速览、冬储蔬菜及青浦本地采收案例；4 月春薯供应与 8 月北方早熟薯采挖已有月报依据，继续补充 |
| 5. 采购指南深化 | 挑选、家庭储存、渠道和囤货原则逐页完善 | 重要建议有来源及适用条件 | 后续推进 |
| 6. 省心采购入口 | 首页先给青浦今晚候选与历史监测价，再展示当月果蔬；场景页和商品购买卡给出快速判断 | 手机端不查月份即可进入商品；核价工具先于详细表格；同口径报价才排序 | 3 种今晚候选、10 种商品购买卡已上线，继续做真实用户测试 |

比价表目前保存在读者本机浏览器，默认选择上海青浦区。盒马与京东的价格随配送地址、门店、会员和优惠变化；站点尚未积累足够的同口径样本，因此暂不提供跨平台最低价结论。[青浦区政府零售监测](/compare/qingpu)仅作本地参考。平台评价数也不能直接充当销量。

每次内容更新运行 `npm run check`，再抽查手机阅读、站内链接与原始来源。资料核实：2026-10-16。
