# 阶段计划与进度

优先完成每月水果、蔬菜清单和可用的零售比价。每条季节线索都要保留品种、产地、观察年份与直接来源；历史市场供应不能写成今年实时行情。

| 阶段 | 工作 | 完成条件 | 状态 |
| --- | --- | --- | --- |
| 1. 月历可用 | 十二个月分列水果、蔬菜；每条注明采收、集中上市或市场供应 | 每月两类都有记录，生成与来源检查通过 | 已完成首版 |
| 2. 零售比价可用 | 同城同商品按净重、优惠、运费换算元/公斤，记录价格口径与日期 | 可录入京东、盒马等平台价格并筛选比较；过期提醒可见 | 已完成本地记录版 |
| 3. 公开价格样本 | 分城市核查各平台高销量或高热度商品；保留商品链接、规格、到手价和采集日期 | 至少两个平台有同城同日、相近规格且可复查的零售样本，才发布公开比较 | 待采集 |
| 4. 月历补全 | 增加更多常见蔬菜、约三十种水果，复核区域和品种差异 | 新条目有直接来源；没有证据的月份标待核实 | 持续进行 |
| 5. 采购指南深化 | 挑选、家庭储存、渠道和囤货原则逐页完善 | 重要建议有来源及适用条件 | 后续推进 |

比价表目前保存在读者本机浏览器。盒马与京东的价格随配送地址、门店、会员和优惠变化；站点尚未积累足够的同口径样本，因此暂不提供跨平台最低价结论。平台评价数也不能直接充当销量。

每次内容更新运行 `npm run check`，再抽查手机阅读、站内链接与原始来源。资料核实：2026-10-13。
