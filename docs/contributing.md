# 投稿与纠错

欢迎补充果蔬品种、地区差异、家庭储存资料，或指出页面中不准确的表述。请优先提交小范围、可以逐条核对的修改。

## 新增或修改建议

1. 写明商品及品种、适用地区、季节或家庭条件。
2. 给每条重要结论添加直接支持它的来源链接，并记录资料发布日期和本次核实日期。
3. 区分“可靠资料”“可重复经验”“待核实”。社区经验请独立归纳，不复制原文或图片。
4. 涉及专业冷库的资料，不换算为家庭保存天数；涉及价格时写明日期、城市、渠道、规格与到手费用。
5. 先按仓库 `templates/produce.md` 整理内容，再运行 `npm run check`。季节数据改在 `data/seasons.json`，不要直接改生成的月份页面。

## 纠错格式

请说明**页面与原句、问题、建议改法、支持资料及适用范围**。若来源冲突，列出双方资料；没有充分依据时建议改为“待核实”，而不是用另一条传闻替换。
