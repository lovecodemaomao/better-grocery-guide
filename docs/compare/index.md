## 查价顺序

1. 在平台上选择同一收货城市和配送地址，再搜同一商品与品种。京东可从[生鲜入口](https://fresh.jd.com/)或商品搜索进入；盒马需在其 App 中选择门店或配送地址。
2. 优先记录实际结算页或订单实付价，同时填入运费、优惠和净重。若只有公开商品标价，选“公开标价”。
3. 页面销量、评价、已售数各有不同含义。可把平台显示的文字原样记在“热度信息”，不把评价数冒充销量。
4. 下单前重新打开来源核价。超过七天的记录会标为需要重查。不同城市或区县的记录不合并排序；同一区县内也需检查配送地址。

<strong>当前覆盖：</strong>站点尚无经过同区、同日、同规格核实的盒马与京东价格对。公开网页经常只显示某一地址的标价，盒马门店价通常需选址登录才能查看；因此这里从用户自己的可追溯记录开始，不能宣称平台实时最低价。后续采集到足够的有效零售记录后，才会加入公开参考报价。
