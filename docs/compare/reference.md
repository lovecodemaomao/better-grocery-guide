## 平台价格怎么看

京东、盒马等平台的价格会随青浦具体收货地址、门店库存、会员资格、配送费和优惠变化。目前还没有足够的**同区、同日、同品种、相近规格**平台报价，所以这里不写未经核实的“平台大约价”。可以在[零售比价表](/compare/)录入实际看到的商品，保留链接或订单凭证，按净重换算元／公斤。

本期水果只有**不同品种混合后的均价 6.36 元／500 克**，不能用来判断苹果或香蕉是否贵；番茄、黄瓜等也没有逐品种价格，暂标待采集。[查看完整监测说明](/compare/qingpu)。

同名蔬菜仍可能因品种、净菜加工、等级、包装和有机认证而不同。报价远高于本页均价时，先核实这些条件和近期同类报价；单凭倍数不能认定欺诈。资料核实：2026-10-13。
