# 梨

2025 年月报预计 7 月上旬有新季早熟梨上市，而年初到春季销售的梨中存在库存果。[夏季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202507/P020250723527712077947.pdf) · [春季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202505/P020250526534774732221.pdf) 因此“全年能买到”不能当作全年自然成熟。

买梨时先确认品种和用途，检查碰伤、破皮与软烂；成箱购买抽查下层。不同品种的脆软口感和耐储性差异较大，**具体品种与家庭保存期限待核实**。要囤货时先用[到手成本方法](/value/)算预计损耗。

资料核实：2026-10-12。适用范围：上述年份全国市场观察。
