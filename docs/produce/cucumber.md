# 黄瓜

黄瓜可来自露地和设施栽培，地域差异较大，本版不写全国统一成熟月。

购买时看是否有破损、渗液、明显软塌或腐烂；按凉拌、生吃或熟食用途选实际规格。黄瓜容易受挤压，网购时需确认包装与配送时间；线下可逐根检查。

明尼苏达大学推广资料提示黄瓜长期处于过低温度会出现冷害，家庭储存不能简单理解为“越冷越好”。具体保鲜时间会随到手状态和家中温度变化，暂不写固定天数。[来源](https://extension.umn.edu/garden-and-home/yard-and-garden/gardening-in-minnesota/harvesting-and-storing-home-garden-vegetables) 食用前用流动水清洗。[清洗依据](https://extension.umn.edu/food/preparing/cooking-at-home/washing-fresh-fruits-and-vegetables)

资料核实：2026-10-12。适用范围：家庭采购的一般检查；产区与品种待补。
