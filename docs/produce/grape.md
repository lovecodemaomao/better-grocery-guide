# 葡萄

2025 年月报记载，葡萄从春末逐步上市，夏季供应增加，北方晚熟品种在 9 月集中上市。[春季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202505/P020250526534774732221.pdf) · [夏季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202507/P020250723527712077947.pdf) · [9 月资料](https://www.agri.cn/sj/jcyj/202510/P020251024329471516815.pdf)

买整串时看底部是否有破粒、渗液或霉变；不同品种的口感和籽量差异应按实际标签确认。运输风险与包装质量相关，网购时关注缓冲包装、到货状态和售后。清洗放在食用前进行。[清洗依据](https://extension.umn.edu/food/preparing/cooking-at-home/washing-fresh-fruits-and-vegetables)

单凭果粉多少判断甜度、家庭可保存的固定天数**待核实**。资料核实：2026-10-12。
