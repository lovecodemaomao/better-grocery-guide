# 冬枣

本页只谈**鲜食冬枣**，不把干制红枣的保存方式或价格拿来比较。农业农村部 **2025 年 7 月月报**预计新产季冬枣随后陆续上市，因此 8 月仅列为当年市场供应预测；产区与品种成熟期仍**待核实**。[月报](https://www.agri.cn/sj/jcyj/202508/P020250827323471313927.pdf)

购买时先区分鲜果和干果，确认标价单位、净重和到货状态。鲜果逐袋查看是否有裂口、软烂、霉变及袋底渗液；网购时确认破损售后。上述是可重复的检查步骤，不据此声称某一颜色必然更甜。

家庭存放期限、不同产区的采收月份及成箱损耗率仍**待核实**，先按近期可吃完的量购买。清洗遵循食用前用流动水清洗鲜果的通用原则。[清洗资料](https://www.samr.gov.cn/xw/mtjj/art/2025/art_2fecc5fdac3b413fae4f53d3e8ca05af.html)

资料核实：2026-10-13。适用范围：2025 年全国市场预测与中国大陆家庭购买完整鲜食冬枣。
