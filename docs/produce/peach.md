# 桃

农业农村部 2025 年市场分析把桃列为春末开始上市、夏季供应增多的水果。[春季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202505/P020250526534774732221.pdf) · [夏季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202507/P020250723527712077947.pdf) 品种与产地跨度大，不能把这一观察当作每年全国统一成熟月。

买桃时检查压伤、破皮和软烂，运输与配送应关注防压包装；准备当天吃和几天后吃，可以选择不同成熟度。桃可采后继续成熟，但到手时已严重损伤的果不适合囤货。[水果成熟与冷冻资料](https://extension.umn.edu/food/preparing/cooking-at-home/food-preservation/freezing/freezing-fruit)
