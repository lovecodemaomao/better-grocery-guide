# 李（李子）

农业农村部 **2025 年 7 月月报**预计李等夏季水果随后上市量增加。这里的 8 月只是那一年的市场供应预测；不同品种、产区和设施条件的采收期仍需分别核实。[月报](https://www.agri.cn/sj/jcyj/202508/P020250827323471313927.pdf)

买完整鲜果时可先查破皮、压伤、霉变和异常气味；想分几天吃，按实际熟度分批购买。大学推广资料把李列为采后仍可继续后熟的水果，但后熟不等于损伤果会恢复品质。[后熟资料](https://extension.umn.edu/food/preparing/cooking-at-home/food-preservation/freezing/freezing-fruit)

具体品种、甜度判断、家庭冷藏期限与整箱损耗率均**待核实**。本页暂不以外皮颜色或手感给出统一成熟度标准。

资料核实：2026-10-13。适用范围：2025 年全国市场预测及完整鲜食李的家庭购买；后熟资料不用于推断中国产区月份。
