# 栽培食用菌

本页指正规渠道销售的鲜栽培食用菌，如双孢蘑菇、香菇等；品种差异尚未逐一核实。**不要购买来源不明的野生蘑菇**。市场监管总局提醒，非专家难以可靠区分野生菌是否有毒。[来源](https://www.samr.gov.cn/xw/zj/art/2023/art_61c1a7f850f542f9bdc0f6f6b66fbb59.html)

## 购买与保存

看包装内是否大量积水、菌体是否黏滑、腐烂或有异常气味；买回后按包装要求冷藏并尽快食用。宾州州立大学农业推广资料建议鲜蘑菇放原包装或纸袋冷藏，避免密闭塑料袋积水加快变质；其中的具体天数不直接用于所有中国品种和家庭条件。[来源](https://extension.psu.edu/preparing-and-preserving-mushrooms)

网购或即时零售要关注冷链、到货时间与包装积水。鲜菌不宜仅因大包装低价而囤积，先按近期烹饪量购买。不同菌种的保存方式和季节仍**待核实**。
