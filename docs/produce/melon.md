# 甜瓜

这里的甜瓜指哈密瓜、香瓜等甜瓜类，**不包括西瓜**。农业农村部 **2025 年 5 月月报**预计甜瓜等夏季鲜果随后大量上市，**7 月月报**又预计 8 月供应继续增加；设施与露地栽培、产区和品种的时间差异尚未细分。[5 月月报](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202506/P020250624550141903948.pdf) · [7 月月报](https://www.agri.cn/sj/jcyj/202508/P020250827323471313927.pdf)

整瓜购买时检查外皮有无裂口、软烂或霉斑，并考虑切开后家庭能否及时吃完。已经切开的果盘要关注切封时间和冷藏条件；若果肉发焉、明显渗汁或变色，不宜购买。[鲜切水果消费提示](https://scjgj.cq.gov.cn/bkzs/spbk/202406/t20240605_13268133.html)

不同甜瓜品种的成熟判断、整瓜与切瓜家庭保存期限仍**待核实**。不把西瓜的保存时限直接套用到甜瓜。

资料核实：2026-10-13。适用范围：2025 年全国市场预测与普通家庭购买鲜甜瓜；鲜切产品判断引用地方消费提示。
