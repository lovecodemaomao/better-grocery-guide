# 番茄

<BuyingCard product="tomato" />

先按用途选：当天做凉拌或生吃，关注成熟度和表面完整；计划几天后做熟食，可以选择尚未完全熟透但已开始转色的果。番茄品种、设施栽培和跨区域供应差异较大，本版**不标全国统一自然成熟月份**。

## 现场挑选

检查果皮是否破裂、渗液、霉变或大片软烂；成熟度不能只看一个颜色，因为品种本身颜色不同。明尼苏达大学家庭园艺资料指出，已经发育成熟并开始转色的番茄可在室内继续成熟，完全未成熟的青果未必能获得好风味。[来源](https://extension.umn.edu/garden-and-home/yard-and-garden/gardening-in-minnesota/growing-tomatoes)

**待核实：**通过所谓“公母”形状判断番茄甜度，没有找到可直接用于家庭购买的可靠依据，暂不采用。

## 渠道与保存

成熟番茄怕挤压，线下可检查每个果的完好程度；配送或网购应看包装、时效和损伤售后。家中尚未成熟的完整番茄可单层放在室温下，定期检查并在成熟后及时使用。[家庭园艺资料](https://extension.umn.edu/garden-and-home/yard-and-garden/gardening-in-minnesota/growing-tomatoes) 资料也指出低温会损害成熟番茄的色泽和风味，因此不要把“越冷越好”当成通则。[储存资料](https://extension.umn.edu/garden-and-home/yard-and-garden/gardening-in-minnesota/harvesting-and-storing-home-garden-vegetables)

切开的番茄与鲜切果蔬按更严格的卫生和冷藏条件处理，不沿用完整果的室温做法。[市场监管总局消费提示](https://www.samr.gov.cn/xw/mtjj/art/2025/art_2fecc5fdac3b413fae4f53d3e8ca05af.html)

**囤货判断：**成熟度相近的一大批会集中变软，家庭采购量应按近期烹饪计划决定。

资料核实：2026-10-12。适用范围：中国大陆家庭采购；未建立全国统一上市月。
