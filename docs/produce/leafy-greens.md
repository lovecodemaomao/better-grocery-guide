# 叶菜

生菜、菠菜、油麦菜等的品种和产地差异大，设施栽培也使供应跨季。本页只提供叶菜的**共同采购与家庭处理原则**，不把整个类别标成同一应季月份。

## 现场挑选

看叶片有无大面积腐烂、黏滑、霉变和明显失水；整袋购买时检查底层是否积水或压烂。外层有少量自然损伤与整棵变质不同，但无法靠外观保证微生物安全。清洗前可去掉受损外叶，食用前用流动水清洗。[明尼苏达大学家庭清洗指南](https://extension.umn.edu/food/preparing/cooking-at-home/washing-fresh-fruits-and-vegetables)

## 渠道与保存

叶菜容易失水、压伤，购买时把配送时间、包装与退换便利计入成本。线下方便逐把检查；即时零售或本地配送可减少途中时间，但仍需在到货时检查。跨区域网购只在可靠包装和冷链条件下考虑，不根据平台名称直接下结论。

到家后先去除坏叶，保持适度干燥并冷藏，避免重物压放；临用前再清洗。家庭冰箱温度、包装和到手新鲜度差异大，本版不承诺统一保存天数。明尼苏达大学的资料显示生菜、菠菜适合低温且保湿的环境，但其给出的理想条件期限不能照搬为每个家庭的安全期限。[储存资料](https://extension.umn.edu/garden-and-home/yard-and-garden/gardening-in-minnesota/harvesting-and-storing-home-garden-vegetables)

**囤货判断：**先按未来几餐用量买；整箱或大捆折扣需要抵消丢弃损耗才划算。[计算方法](/value/)

资料核实：2026-10-12。适用范围：中国大陆家庭采购；单一叶菜品种需要更具体的指南。
