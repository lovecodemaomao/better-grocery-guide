# 西瓜

2025 年春季月报预计西瓜陆续上市，夏季月报记载北方主产区供应增加；到秋季北方产区逐步进入尾期。[春季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202505/P020250526534774732221.pdf) · [夏季资料](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202507/P020250723527712077947.pdf) · [秋季资料](https://www.agri.cn/sj/jcyj/202510/P020251024329471516815.pdf) 这些是年份观察，不能推断所有地区同时低价。

完整西瓜选购时检查外皮是否破裂、渗液或明显腐烂；切开的瓜按鲜切果蔬的冷链和保质信息购买，不沿用完整果的存放方式。[市场监管总局提示](https://www.samr.gov.cn/xw/mtjj/art/2025/art_2fecc5fdac3b413fae4f53d3e8ca05af.html)

敲击声判断成熟度、不同品种家庭保存天数等具体说法**待核实**。资料核实：2026-10-12。
