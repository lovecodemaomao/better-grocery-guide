# 樱桃

2025 年春季农业农村部月报预计国产樱桃随气温回升逐步上市；这属于当年市场预测，不是所有产区和设施樱桃的固定产期。[来源](https://www.moa.gov.cn/ztzl/nybrl/rlxx/202505/P020250526534774732221.pdf)

樱桃属于易压伤的鲜果。购买时检查盒底有无渗液、霉变或大量破皮，网购时核对到货时效和破损售后；购买量按近期食用计划安排。关于品种、不同产区成熟期及家庭保存期限，**待核实**，本页暂不提供数字。

资料核实：2026-10-12。适用范围：上述 2025 年全国市场预测。
