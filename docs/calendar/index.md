## 怎么用这份清单

- **产地采收**：资料明确提到产区采摘；购买时再核对产地和批次。
- **集中上市**：资料明确提到上市量增多；集中上市不保证零售价最低。
- **市场供应**：可能来自库存、设施栽培或其他产区，适合补充日常采购选择。

每月页面还会给出水果、蔬菜的完整线索和直接来源。做采购决定时，结合[同城零售比价](/compare/)和实际品质。资料核实：2026-10-13。
