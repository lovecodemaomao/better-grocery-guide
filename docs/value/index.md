# 算清真正的到手成本

首期不发布“全国参考价”或平台排行榜。实际价格须带日期、城市、渠道、规格和来源；农业农村部的[批发价格数据](https://data.moa.gov.cn/nyb/pc/index.jsp)可以观察批发市场趋势，不能直接写成消费者零售到手价。

## 三步计算

1. **实付金额**＝商品付款额＋运费及包装费－实际获得的优惠。
2. **可食用重量**＝到货净重－不可食用部分－损坏或变质丢弃部分。
3. **有效单价**＝实付金额 ÷ 可食用重量。若为了拿优惠而多买，还要估计未来吃不完的损耗。

例如两袋同类苹果，A 袋净重 2 千克、实付 20 元，到家有 0.2 千克不能食用，有效单价约 11.1 元/千克；B 袋净重 1 千克、实付 12 元且无损耗，有效单价 12 元/千克。这个数字仅演示算法，**不是市场价格资料**。

时间成本不用强行换算成统一货币。可以在“是否要额外跑一趟”“配送能否节省必要时间”之间直接权衡。批量采购还应考虑冰箱空间和家庭消耗速度。

以后若收集价格观察，每条使用独立记录，字段见仓库 `data/price-observation.schema.json`；不在商品指南里写“某平台长期更便宜”。
