# 今晚买菜

先选一两样能用于今晚或明天的菜，再按实际人数和餐数决定数量。下面是**购物组合示例**，不承诺固定花费或当天低价。

## 两种省事思路

- **想吃新鲜叶菜**：选一把[叶菜](/produce/leafy-greens)，到店先看袋底、叶片和是否积水；打算明天再吃，带回家及时处理并冷藏。可配[番茄](/produce/tomato)，按生吃或熟食选择成熟度。
- **想减少明天再买菜的次数**：选[马铃薯](/produce/potato)搭配[番茄](/produce/tomato)。马铃薯检查发青、发芽和软烂；有避光通风空间时，再考虑比价买大包装。

## 买之前看三件事

1. 今天或明天会不会用？易失水的叶菜先按近期餐数买。
2. 到手净重与损耗怎么算？价格高低先看[青浦区历史参考](/compare/reference)或同店近期报价。
3. 赶时间时选能看实物、路程短的渠道；配送到家也要检查果况。[渠道判断](/channels/)

地区与年份会影响当月供应；本页不是实时价格或食谱营养建议。资料核实：2026-10-13。
