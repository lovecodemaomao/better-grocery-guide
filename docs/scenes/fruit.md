# 买水果

先看本月有资料的候选，再决定是**这两天吃**还是**打算分批吃**。同名水果的品种和产区可能差很多；“有供应”不保证新采摘或便宜。

<CurrentMonth category="fruit" />

## 赶时间时这样选

- **想立刻吃**：少量购买、现场检查成熟度和碰伤。选[香蕉](/produce/banana)看果柄与内侧；选[草莓](/produce/strawberry)看整盒底部。
- **想分几天吃**：先看[苹果](/produce/apple)或具体品种的[柑橘](/produce/citrus)，核对净重、果况和能否妥善存放。首次买不熟悉的品种，先小量试。
- **想网购整箱**：查看商品页上的包装、实际净重和破损售后，再算[到手成本](/value/)；不要只看“应季”标签。
