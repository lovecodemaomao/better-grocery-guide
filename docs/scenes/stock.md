# 备点存货

先问自己：**放在哪里、多久会吃掉、买多能省多少钱**。大包装的每公斤标价较低，也可能因损伤和丢弃而不划算。[完整成本算法](/value/)

## 可以先比较的食材

- [苹果](/produce/apple)：完整果可冷藏并定期检查；整箱网购先核对品种、净重和破损售后。损伤果先吃，专业冷库期限不能套用到家用冰箱。
- [马铃薯](/produce/potato)：有避光通风空间时可比较大包装；检查发青、发芽、潮湿和软烂。
- [大白菜](/produce/cabbage)：按实际用量选择整颗或切份；切份更要留意包装、冷藏和到手状态。

## 先少买的情况

[草莓](/produce/strawberry)容易受压、[叶菜](/produce/leafy-greens)容易失水；没有明确的近期食用计划时，不宜仅因整箱折扣而囤。[香蕉](/produce/banana)还要考虑成熟速度。

具体家庭保存天数受品种、到手果况和冰箱条件影响，本页不提供统一保证。资料核实：2026-10-13。
